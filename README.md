# 🦷 OralScan – AI-Based Oral Cancer Detection

## 📌 Overview
**OralScan** is a deep learning-based medical imaging system designed for early detection of oral cancer using oral cavity images.  

The project leverages multiple state-of-the-art deep learning architectures including **CNN**, **InceptionV3**, and **Vision Transformer (ViT)** combined with **ensemble learning** to achieve higher accuracy and robustness.

The final model is deployed on **Hugging Face** for real-time inference.

---

## 🚀 Features
- 🧠 Multi-model deep learning system (CNN + InceptionV3 + Vision Transformer)
- ⚡ Ensemble learning for improved accuracy and stability
- 🏥 Medical image classification for oral cancer detection
- 📊 Optimized evaluation metrics and performance tuning
- 🌐 Deployed on Hugging Face Spaces
- 🔬 Research-oriented AI healthcare application

---

## 🏗️ Model Architecture
OralScan uses an ensemble of three powerful models:

- **CNN (Convolutional Neural Network)**  
  Extracts local image features and patterns.

- **InceptionV3**  
  Captures multi-scale spatial features using advanced convolution blocks.

- **Vision Transformer (ViT)**  
  Uses self-attention mechanism to understand global image context.

### 🔗 Ensemble Strategy
Final prediction is generated by combining outputs from all models to improve:
- Accuracy
- Generalization
- Robustness against noisy data
